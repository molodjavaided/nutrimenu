## Что за проект

**NutriMenu (бренд Plate)** — SaaS для владельцев кафе и ресторанов: цифровое меню с полным профилем блюда (КБЖУ, состав, аллергены, варианты и замены), доступное гостям по QR-коду. Владелец ведёт меню в дашборде, гость сканирует QR и видит брендированное фильтруемое меню.

**Владелец проекта:** Юрий. **Язык общения:** русский. Код, комментарии, коммиты — английский.

**Бизнес-контекст:** общепит в РФ обязан доводить до гостя пищевую ценность блюд (с 01.09.2026 — новые Правила, ПП РФ № 1820). NutriMenu закрывает это требование и даёт гостям прозрачность. Монетизация: тарифы TEST (триал 14д) / START / STANDARD (990 ₽/мес) / CUSTOM + услуга оцифровки меню (5 000 ₽).

**Текущая фаза:** полировка продукта и первые платящие клиенты. Главные блокеры: нет платёжной интеграции (планируется ЮKassa), email не доставляется (Resend без домена).

## Стек

- **Next.js 16** (App Router) + TypeScript. ⚠️ Версия новее твоих обучающих данных — перед написанием кода читай доки в `node_modules/next/dist/docs/`. Вместо `middleware.ts` — `proxy.ts`.
- **Postgres (Neon) + Prisma 7** (`prisma/schema.prisma`, доступ через `lib/db.ts`)
- **Auth:** JWT (jose) в httpOnly cookie, роли `admin | owner`, tokenVersion для отзыва сессий, impersonation с TTL 2ч — всё в `lib/auth.ts`
- **UI:** Tailwind CSS v4, shadcn/ui, lucide-react; бренд-цвета inline: `#2C2950`, `#B0A6DF`, `#EAE7F8`, `#FEFEF2`
- **Server state:** TanStack Query v5 (новый код); часть `/dashboard/*` ещё на useEffect — мигрируется по мере правок
- **Forms:** react-hook-form + zod. **DnD:** @dnd-kit
- **AI:** Gemini (импорт ТТК, штрихкоды, обогащение ингредиентов), Perplexity Sonar (fallback), Claude (резерв). Новые AI-провайдеры не добавлять.
- **Прочее:** Vercel Blob (файлы), Upstash Redis (rate-limit), Telegram-бот (брифинг, переписка владелец↔админ), Sentry, Resend (заглушка)

## Модель питания (ядро продукта)

КБЖУ блюда считается на нескольких уровнях: плоские поля → варианты (`variantGroups`, взаимоисключающие, переопределяют КБЖУ) → модификаторы (`modifierGroups`: addon добавляет, replace заменяет ингредиент) → состав (`composition` из `IngredientRef` с коэффициентами обработки). Финальный расчёт — `resolveNutri()` в `lib/utils.ts`. Эти данные лежат в Json-полях MenuItem.

## Состояния пользователя (`lib/plans.ts`)

`trial` → `awaiting_plan` (триал истёк, меню скрыто) | `paid` → `grace` (30д) → `expired`. Бонусные лимиты (bonusItems/bonusAiImports/…) выдаёт админ, переживают смену плана.
