## Фаза 4 — Вспомогательные скрипты (адаптировать, не копировать вслепую)

1. **`scripts/probe_model.py`** (или `.ts`) — минимальный «пробник»: один вызов LLM
   на реальном примере блюда через ваш текущий провайдер, печатает сырой ответ и модель.
   Цель — быстро проверять промпт/модель импорта перед изменением флоу. Напиши под ваш стек
   (Gemini/Perplexity SDK, ключи из `.env.local`), НЕ тащи model-id из MyResult.
2. **`scripts/check_env.(py|ts)`** — хелсчек env перед деплоем: проверяет наличие ключей,
   ловит кириллицу в токенах и задвоенные слэши в URL (Neon/Vercel/провайдеры).
   Адаптируй список переменных под `.env.local` NutriMenu.

Оба скрипта — маленькие, автономные, без внешних зависимостей сверх уже установленных.
